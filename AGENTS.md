# DreamDev

## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues via the `gh` CLI (repo: `shakibdshy/DreamDev`). See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role triage vocabulary: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
